# Q4: NotebookLM evaluation (BUS5001 Assessment 3)

Scenario: preparing an ESG briefing on IFRS S2 and Australian mandatory climate reporting.

Files
- `q4_experiment_log.csv`: one row per test (feature, prompt, output summary, citations, checks, result, notes)
- `q4_notebooklm_outputs_raw.txt`: raw text copied from NotebookLM for each test (T1 to T8)
- `sources.md`: the four website sources added to the notebook

Method: same notebook and fixed prompts for every test; outputs copied as plain text; claims checked against the source pages. NotebookLM's own "check these claims" answers are recorded separately from independent checks.

Limits: one notebook, one scenario, four sources, mostly single runs.
